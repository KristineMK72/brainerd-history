# Brainerd — A Crossing on the Mississippi

A splashy Astro site telling the history of Brainerd, Minnesota: Ojibwe homeland, Northern Pacific railroad town, lumber and paper mills, lakes-country tourism, and the people who shaped it.

## Local

```bash
npm install
npm run dev
```

## Deploy

Linked to Vercel as `brainerd-history`. Push to `main` and it builds with the Astro preset.

Framework: Astro. Output: static (`dist`).
