# Brainerd — A Crossing on the Mississippi

A visual history site about Brainerd, Minnesota: Ojibwe homeland, Northern Pacific railroad town, lumber and paper mills, lakes-country tourism, and the people who shaped the place.

Static HTML + CSS. No build step. Ships cleanly to [Vercel](https://vercel.com).

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
npx serve
```

## Deploy to Vercel

1. Open [vercel.com/new](https://vercel.com/new) and import `KristineMK72/brainerd-history`.
2. Framework preset: **Other** (static).
3. Leave the build command empty. Vercel will serve `index.html` from the repo root.
4. Click **Deploy**.

From the CLI after `npx vercel login`:

```bash
npx vercel
npx vercel --prod
```

## What’s on the page

- A chaptered story of the crossing, the shops, lumber, paper, and the lakes
- Notable people including Lyman P. White, the Brainerd family, C. Elmer Anderson, Charles Bender, Bullet Joe Bush, Zane Smith, Leon Lum, and George Montgomery
- Timeline from Pike (1805) to Donnybrooke / BIR (1968)
- Historic photographs from Wikimedia Commons plus atmospheric Unsplash images

## A note on sources

Some well-known episodes have competing dates or origin stories:

- The town name honors the Brainerd family. Local newspaper research argues it was specifically Lawrence Brainerd, not only Ann Eliza Brainerd Smith.
- Baby Face Nelson’s First National Bank robbery is October 23, 1933 in detailed Brainerd reconstructions and October 27 in some later summaries.

Principal references: Crow Wing County Historical Society, City of Brainerd History Notes, Brainerd Dispatch sesquicentennial reporting, National Register listings, National Baseball Hall of Fame, BIR official history.
